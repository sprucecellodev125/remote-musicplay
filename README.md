# remote-musicplay
A music player with web-based remote controls for home

### Install instructions
- Clone this repository (run `git clone https://github.com/sprucecellodev125/remote-musicplay; cd remote-musicplay`)
- Create virtual environment (run `python -m venv .venv`)
- Install requirements (run `pip install -r requirements.txt`)
- Create `music/` directory (run `mkdir music/`)
- Copy all your music files to `music/`
- Run `python3 main.py` 🎊
